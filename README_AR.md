# MY COACH 2027 — حزمة Klencode IDE

لعبة ويب عربية تجريبية لإدارة مسيرة مدرب كرة قدم. واجهة RTL، ملعب Canvas تفاعلي، ولا تحتاج إلى مكتبات أو اتصال خارجي.

## تشغيل سريع

1. ارفع ملف `MY_COACH_2027_KLENCODE.zip` إلى Klencode IDE إذا كان يدعم استيراد ZIP.
2. فك ضغط الحزمة إن طلب IDE ذلك، وتأكد أن `index.html` في جذر المشروع.
3. افتح المعاينة/Preview على `index.html`.
4. بديل محلي: افتح الطرفية داخل مجلد المشروع وشغّل `npm start` أو `node server.mjs`، ثم افتح العنوان الذي يظهر.

> إذا لم يقبل IDE ملفات ZIP، فك الضغط وارفع **محتويات المجلد** بحيث يكون `index.html` هو الملف الرئيسي.

## ما يعمل في هذا الإصدار

- لوحة مباراة على ملعب علوي، كرة ولاعبون يتحركون، نتيجة ووقت المباراة وأهداف.
- بدء/إيقاف/استئناف المباراة، سرعات 1× و2× و4×، إعادة المباراة، ثم الانتقال للمباراة التالية.
- تغيير أسلوب الفريق والضغط وطريقة بناء اللعب والتشكيلة أثناء المباراة.
- إجراء تبديل بين الأساسي والبديل مع حد أقصى تجريبي قدره 5 تبديلات.
- قائمة الفريق، واختيار القائد ومنفذي الجزاء والركلات الحرة.
- سوق محلي تجريبي يخصم قيمة اللاعب من الميزانية ويضيفه إلى البدلاء.
- إدارة ملف المدرب والجنسية والعمر وهدف مجلس الإدارة.
- التدريب يستهلك ميزانية ويغيّر اللياقة/التقييم/المعنويات؛ المؤتمر الصحفي يؤثر في المعنويات.
- جدول دوري تجريبي، سجل للمسيرة، وحفظ تلقائي داخل المتصفح.
- 3 خانات حفظ منفصلة، مع تصدير واستيراد ملف JSON.
- واجهة عربية متجاوبة وأيقونة مدمجة في ملفات المشروع.

## البيانات والحدود

هذه **نسخة محلية تجريبية / MVP** وليست لعبة عالمية مكتملة أو منتجًا رسميًا. قوائم اللاعبين والخصوم والانتقالات والدوري بيانات تدريبية/تجريبية وليست موثقة لموسم 2026–2027. لا يوجد خادم أو حسابات مستخدمين أو لعب عبر الإنترنت أو تحديث بيانات خارجي. الحفظ التلقائي وخانات الحفظ مرتبطة بالمتصفح والجهاز؛ استخدم تصدير JSON لنقل المسيرة.

تحتاج المنافسة الفعلية على نطاق ألعاب عالمية إلى مراحل تطوير إضافية: بيانات مرخّصة ومتحقق منها، محرك محاكاة وتوازن أعمق، خصوم AI موسميون، مسابقات وقواعد تسجيل حسب الاتحاد، اختبار واسع للأجهزة، وأصول فنية/صوتية احترافية. لا تدّعي هذه الحزمة أن تلك الأنظمة مكتملة.

## التقنية

HTML5 + CSS + JavaScript عادي + Canvas. لا توجد حزم خارجية. `npm start` يستخدم خادم Node.js صغيرًا بدون اعتماديات.
